# folia-Lyrics 0.5.0

Windows 歌词显示器，自身不播放音频。使用 Windows GSMTC 获取其他播放器公开的歌曲和进度，使用 WASAPI 默认输出设备的混合声音驱动原版歌词动效。

GitHub 发布页：[0.5.0 发布页](https://github.com/KONEWS/folia-Lyrics/releases/tag/desktop-v0.5.0)。完整便携包为 `FoliaLyrics-0.5.0-win-x64.zip`，解压后运行 `FoliaLyrics.exe`；也可下载独立程序 `FoliaLyrics-0.5.0-win-x64.exe` 直接运行。发布页提供 `SHA256SUMS.txt` 用于核对压缩包和程序。本地重新编译默认输出到 `release/0.5.0/win-x64/FoliaLyrics.exe`。

0.5.0 整理独立 .NET 桌面版的版本编号，沿用 0.4.40 的功能。

## 样式与设置补齐预览版（2026-10-25）

[本次预览版下载页](https://github.com/KONEWS/folia-Lyrics/releases/tag/desktop-v0.5.0-preview.20261025)：独立程序为 `FoliaLyrics-0.5.0-preview.20261025-win-x64.exe`，完整便携包为同名 ZIP，另附 `SHA256SUMS.txt`。程序内部版本仍为 0.5.0；本包包含上游 v0.7.22 和以下补齐功能，分析模型已随包提供。退出旧版后再运行。

- 14 种动态样式和静止样式继续复用上游渲染器；加入随机切换、候选池、立即重抽、样式及背景快捷参数，以及支持暂停和应用的示例预览。
- 字体设置提供本机字体列表、搜索、预览与上传；花火等自带字号布局的样式显示各自提示。关闭译文不会再误关下一句预览，字幕区域隐藏开关单独保存。样式及背景切换复用上游柔焦过渡。
- 视频背景可选择本地文件或 HTTPS 地址，支持透明度和填充方式，静音跟随外部播放进度；重启恢复本地选择，文件丢失时提示重新选择，透明窗口暂不显示视频。按上游设计，视频选择不随外观短码或 JSON 传递。
- “通用 → 智能动感”保留关闭、只用已分析、开启三个模式。开启后选择与当前播放器版本相同的完整音频，使用上游 Beat This! 和 htdemucs 模型分析拍点与鼓点，不播放音频；结果按歌曲保存，下次播放可复用。需要支持 WebGPU 的显卡与运行环境；不同剪辑或现场版本须分别分析。
- 新增设置可从统一搜索定位；随机偏好、智能动感开关与效果强度随视觉配置导入导出，音频文件及本曲分析关联保留在本机。构建会先下载并校验约 133 MB 的模型文件，首次构建需联网。

## 0.4.40 播放器切换与歌词性能

- 椒盐等商店应用优先读取高分辨率图标，自动更新已有绑定；从首页或设置启动音乐软件成功后，直接跟随所点击的软件，无需再从左上角切换。启动失败保留原来源，较晚完成的启动不会覆盖之后的手动选择；歌词窗口前置并临时置顶约 5 秒。
- 暂停时避免播放器首次滞后进度使歌词回跳；后续暂停中拖动仍更新画面。系统媒体连接故障提示约 2.5 秒后收起，同一次故障不反复弹出。
- 点击左上角应用标题，直接从下拉列表切换跟随的音乐软件。标题和所有选项统一使用选定的“轻缓频谱”单色八条音浪，保持基本轮廓，播放时以最大约 1.4 px 的幅度缓慢起伏，暂停时定格，自动跟随和未运行项保持静止。倒数第二条保持缩短，下拉列表跟随“设置透明度”滑块。已绑定但未运行的商店应用和传统程序均可预选，启动后自动跟随；同名程序无法唯一识别时，可在运行后直接选择对应播放器。
- 切换播放器不再先清空为未连接页面，选择当前播放器保留会话与歌词；切回自动跟随会重新选择正在播放的应用。同曲歌词等新版本解析成功后再替换，失败保留当前画面。快速切歌保留渲染器约 200 毫秒，较慢匹配再释放旧场景；旧歌词不会跟着新歌时钟跳动，字体就绪后再提交新画面。
- 同一原生消息只处理一次，再分发给界面；歌词只变更说明或封面时复用解析结果。菜单关闭时减少选项计算，切换后取消过期封面加载，稳定媒体信息不再触发额外刷新。

## 0.4.39 可靠性、窗口记忆与诊断

- 手动在线选择先检测实际歌词内容，下载和检测可取消且有总时限；选择无法写入时会提示，并在当前运行期间保留。QQ 找到高匹配逐字歌词后会先显示，其他来源继续补全候选。
- 保存失败会明确显示；恢复快捷键冲突时可从托盘恢复。默认歌词动效报错后可以重试，频谱更新不再额外驱动播放时钟。
- 窗口位置、大小和最大化状态会保存；换显示器或小屏恢复时会确保窗口仍可见。
- 字幕使用当前歌词和设置的字体准备布局，上传字体恢复与失败回退也经过就绪处理。
- 设置新增可搜索的诊断与支持，可复制精简状态和最近错误类型，或打开日志目录。
- 下载包为 Windows x64 自包含便携版，包含说明和许可证；旧版本继续保留在各自目录。

## 0.4.38 设置搜索与逐字歌词优先

- 主设置、歌词样式设置和背景设置顶部提供统一搜索；候选显示所属页面、样式和分组，点击后展开对应区域、滚动并聚焦控件。可搜索未启用样式与背景的参数，查看参数不会改变当前画面；条件参数尚未显示时提示先检查哪个选项。
- 自动歌词保留本地文件和手动选择优先。没有本地文件或手动绑定时，优先选择 QQ 中匹配度最高的实际逐字歌词；QQ 没有逐字版本时，选择其他启用来源中匹配度最高的逐字歌词。全部来源均无逐字版本时，回退到最高匹配的可用 QQ 同步歌词，再回退其他来源。
- 实际解析下载内容后判断逐字时间轴，损坏或只有逐行的 QRC 不会误获逐字优先。启用联网与 QQ 时，旧自动缓存按新策略检查一次，手动选择和离线缓存继续保留；首次匹配需检查完整候选，可能比以前等待更久。
- 在线候选默认显示 5 个，多余结果可展开与收起；选中结果位于折叠区时显示当前版本提示。
- 下载包包含 Windows x64 自包含单文件程序，旧版本继续保存在各自的文件夹。

## 使用
1. 在常用播放器中播放音乐，再打开 FoliaLyrics.exe。
   也可先打开 Folia，默认自动扫描常见音乐软件，并在确认列表中询问是否添加；之后每 10 秒检查一次新打开的常见播放器，后台发现会排队等待回到窗口后确认。微软商店音乐应用使用 Windows 应用入口识别和启动，自定义目录中的便携版可在运行后识别；未识别的软件可在设置 → 播放器 → 音乐软件快捷启动中选择 `.exe` 手动绑定，也可点击“扫描音乐软件”重新检查安装记录与运行进程。首页显示从程序提取的图标，点击图标即可启动。默认预留三个位置：绑定两个时第三个显示 `+`，绑定三个时第四个显示 `+`，继续绑定后始终在末尾保留添加入口。点击 `+` 直接进入设置绑定新软件；关闭“首页显示添加按钮”可隐藏所有 `+`，已绑定的图标仍保留。解除绑定只移除快捷方式，手动扫描或播放器重新启动后可再次发现；选择“不再发现”可屏蔽，并可在设置中“恢复发现”。传统程序路径失效时重新选择程序。
2. 识别到歌名、歌手和进度后，自动从启用的在线歌词源匹配；已有本地歌词或缓存时优先使用。
3. 不准确时，进入设置的“在线歌词”，修改歌名/歌手搜索并点击合适版本，选择会自动记住。也可添加音乐目录，或导入带内嵌歌词的音乐文件及 LRC / TTML / YRC / QRC / FIA。
4. 底部三个按钮控制外部播放器的上一首、暂停/继续、下一首；切歌后自动匹配新歌词。
5. 从首页或设置启动音乐软件成功后，Folia 会直接跟随所点击的软件，原先固定了其他来源也会更新；启动失败保留原来源。仍需在音乐软件中播放歌曲，媒体会话出现后自动同步。启动时歌词窗口会立即前置并临时置顶，成功后保持约 5 秒，避免被刚打开的播放器遮住；之后恢复原来的置顶设置，期间手动修改置顶会立即生效。椒盐等商店图标优先读取高分辨率资源并修正透明留白，已有绑定也会更新。
6. 点击窗口左上角标题，直接在下拉列表中选择自动跟随或运行中的应用；一致的音浪图标在播放时起伏，暂停时静止。已绑定但未运行的传统程序和商店应用均可预选。
7. 顶栏直接选择 14 种动效、显示译文和窗口置顶；右侧设置仍可调整歌词匹配、时间微调和声音响应。
8. 顶栏按钮进入/退出全屏；Esc 退出全屏、关闭设置或恢复控制栏。窗口与全屏沉浸时，鼠标移到顶部呼出顶栏及设置入口，移到底部呼出播放控件，离开后收起；开启鼠标穿透后，Ctrl+Alt+L 或双击托盘图标恢复。

## 兼容性与边界
- 目标系统为 Windows 11 x64。内置 .NET，无需用户另装 .NET；界面需要系统安装 Microsoft Edge WebView2 Runtime。
- 自动同步依赖播放器支持 Windows 系统媒体接口。不是听歌识曲或语音转歌词，也不读取播放器进程内存。
- 系统媒体接口通常不提供歌词。本版从 QQ 音乐、网易云音乐、酷狗音乐、LRCLIB 搜索歌词，并保留本地导入。在线请求仅传歌名、歌手、专辑、时长和已选歌曲标识；不上传音频、不修改原音乐。
- 播放器未提供进度时，可以在设置中开启手动歌词时钟，只推进歌词。
- 歌词偏移按歌名、歌手、专辑和时长区分版本，同一版本可跨播放器复用。版本信息暂缺时保留本次校准，信息补齐后保存；无播放器的独立歌词导入按歌词内容保存，避免同名的不同时间轴共用校准。旧版偏移只迁移到一个识别出的版本。
- 逐行 LRC 不能自动变成精准逐字歌词；逐字动效准确度依赖文件原有时间轴。本地加密歌词容器需先转换；在线 QQ QRC / 酷狗 KRC 由适配层解码。
- 声音响应读取默认音频输出设备的混合声音，仅在内存计算，不读取麦克风、不保存录音。ASIO、独占输出或其他设备可能没有声音响应；它不影响独立的时间同步功能。
- 最小化窗口会暂停声音采集，恢复窗口后按声音响应开关重新连接。媒体信息异步读取超过 3 秒会重新连接，迟到的旧结果不会覆盖当前状态。
- 配置、索引和缓存位于 %LOCALAPPDATA%\FoliaLyrics。
- 已在本地 Windows 11 上编译并启动 EXE，使用椒盐音乐验证播放进度、暂停继续、上下首、绘光切换、最大化还原及亚克力外观。长时间稳定性、多屏/DPI 与声音响应强度仍需进一步确认；完整范围见 VALIDATION.md。
- 程序未做商业代码签名，首次运行可能显示来源未知提示；不要关闭系统防护。需要核对文件时可查看交付的 SHA-256。

## 外部播放器控制
- 使用 Windows GSMTC 的 Play / Pause / SkipPrevious / SkipNext 请求；音乐仍由原播放器解码和输出。本软件不会启动音频播放、抢占音频设备或注册自己的播放会话。
- 先在音乐软件中播放一首歌。底部按钮跟随当前连接的播放器；左上角标题菜单或设置中的“选择播放器”可固定应用，默认自动选择后持续绑定，暂停时也保留。多个播放器同时运行时，可明确选择要控制的应用。
- 按钮是否可用取决于播放器报告的能力。没有会话、已断开或未开放操作时禁用对应按钮。只支持切换播放状态的播放器使用系统提供的 Toggle 请求。
- 操作前校验会话标识、歌名/歌手/专辑；异步读取期间换歌或换来源会取消旧操作。连续点击不会排队执行；超过等待期限会显示错误，不自动重发。
- 收到成功回复只表示播放器接受请求；播放图标和歌词进度仍由实际会话数据更新。操作失败不会假装已暂停或切歌。
- 正常和等待中的控制只显示图标，成功回复不显示文字。仅操作失败或回复超时时出现错误；未连接或未开放操作时，相应按钮禁用并通过悬浮提示说明。
- 沉浸模式隐藏按钮，按 Esc 恢复。鼠标穿透时用 Ctrl+Alt+L 恢复操作。
- 手动歌词时钟仍是独立计时工具；它的“开始/暂停计时”仅控制歌词。手动模式下需要自行对齐时间，底部按钮仍只控制外部播放器。

## 在线匹配规则
- 默认启用四个歌词源，各源可独立关闭；总开关关闭联网后仍可读取已缓存的歌词。
- 手动选择的在线版本优先；否则先找本地歌词，再用在线缓存，最后联网。导入本地歌词会清除当前歌曲的在线手动绑定。
- 歌名、歌手、专辑和时长用于计算匹配分数；没有本地文件或手动绑定时，自动选择会在可用同步歌词中按逐字优先规则选择最高匹配版本，不再以旧的时长阈值限制自动选择。
- 自动选择依次优先 QQ 实际逐字、其他启用来源实际逐字、QQ 逐行和其他来源逐行；每一级均选择匹配分数最高的可用版本。各启用源并行搜索，每源搜索上限 15 秒，单候选下载上限 2 秒、解析上限 5 秒；采用后不会因迟到结果反复换词。在线候选仍按 QQ、酷狗、网易云、LRCLIB 展示，同一来源内按分数降序；默认显示 5 个，其余可展开。展示数量不限制自动匹配检查范围。
- 普通缓存按歌名、歌手、专辑和时长隔离，最多保留 500 条；手动选择单独保存在 `online-lyrics/bindings`，不随普通缓存淘汰。旧版手动缓存会自动迁移；“重新自动匹配”会清除当前绑定和缓存后再按本地优先顺序查找。
- 启用联网与 QQ 时，旧策略自动缓存（含 QQ 逐行歌词）按新策略检查一次；没有新的可用版本时，验证并保留可用旧缓存，只显示一次最终选择。检查结果随缓存记住，避免每次播放重复联网；“重新自动匹配”可再次检查。手动选择、本地歌词、当前策略缓存，以及关闭联网或禁用 QQ 时的缓存直接使用。
- 缓存位于 %LOCALAPPDATA%\FoliaLyrics\online-lyrics，与原音乐文件分开。快速切歌会取消旧请求，旧结果不会覆盖新歌曲；网络请求不会阻塞播放进度轮询。
- 遇到限流遵守 Retry-After。同一服务的请求保持串行并至少间隔 300 ms，设置请求超时和响应体积上限。
- 接口可用性和歌词覆盖取决于第三方。本版不要求输入账号；截图中的汽水、Apple Music、Spotify 歌词源未接入。

## 工程边界
此衍生工程使用独立的 .NET 桌面宿主。`MediaMonitor` 负责读取与绑定会话，`MediaTransport` 负责能力校验与请求串行化，`WindowsMediaControlTarget` 是 Windows API 适配器；`PlaybackControls.tsx` 仅发送控制请求并显示系统返回状态。`native/Online/OnlineLyrics.cs` 是多源门面，各 provider 负责网络与数据标准化；WebView 界面仅使用统一消息协议，原 Folia 的 Web/Electron Omni 模块保持原状。原版 QRC 解码器及歌词解析器复用在 `parseDesktopLyrics.ts`，渲染器只接收标准歌词数据。

## 重新编译
安装 Node.js 24+ 与 .NET SDK 10，运行 build-windows.cmd。或执行：
```
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck:desktop
npm run build:desktop
npm run test:desktop
node tools/package-web.mjs
dotnet publish native/FoliaLyrics.csproj -c Release -r win-x64 --self-contained true -o release/0.5.0/win-x64
```

`build-windows.cmd` 从 `native/FoliaLyrics.csproj` 读取版本，输出到 `release/<版本>/win-x64/`。每次更新递增原生版本号后重新构建，即可得到独立的版本文件夹；手动执行上述发布命令时，也应将输出路径中的版本同步更新。

本机已将 Node.js 24 与 .NET SDK 10 单独准备在 `%LOCALAPPDATA%\FoliaLyricsBuild`；构建脚本会优先使用该目录中的工具，并检查所需版本，不修改系统 PATH。其他电脑仍需准备构建环境。
