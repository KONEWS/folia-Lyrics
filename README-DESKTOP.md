# folia-Lyrics 0.4.26

Windows 歌词显示器，自身不播放音频。使用 Windows GSMTC 获取其他播放器公开的歌曲和进度，使用 WASAPI 默认输出设备的混合声音驱动原版歌词动效。

## 0.4.26 更新

- 普通“歌词设置”去掉重复的标题和关闭按钮，让内容获得更多垂直空间。点击设置页外的空白区域，或再次点击顶栏设置按钮即可关闭；小窗口中的按钮也不会被面板遮住。面板内操作和弹出的播放器选单不会误关设置。Esc 仍可关闭设置。
- 新增“设置透明度”滑块，主设置、歌词样式设置、背景设置、分词设置和图片素材窗口共享同一材质透明度；拖动即时预览，松手、失焦或关闭时保存，并支持视觉配置导入导出。它不改变歌词透明度、动画、时钟或播放页面透明背景。
- 桌面默认配色改为蓝色系；启用封面主题时保留歌曲的主色相，只调整明暗和对比度。刷新主题不会把暖色封面变成互补色，缺失、黑白或读取失败的封面继续使用默认／中性配色。

## 保留的 0.4.25 更新

- 设置、二级菜单和素材窗口使用更透明的玻璃底色与统一圆角；保留模糊及局部暗化，增强浮层说明文字的可读性。滚动条去掉两端箭头按钮，保留细轨道、滑块和滚动操作。
- 调整样式菜单的选项区与底部入口，统一行高、内距和圆角，选中行完整可见；所有桌面二级菜单和设置浮层采用同一套轻量弹出动画，系统要求减少动态效果时关闭动画。
- 一级和二级菜单、通知、设置及图片窗口共用桌面控件样式和封面配色；原版参数面板弹出的菜单也跟随当前主题。
- 修复播放器返回多个图片格式名称时封面地址无效的问题；同曲封面晚到或读取暂时失败会重试，补到封面后同步更新界面与歌词主题。
- 底部正常、等待和成功操作不再显示文字；保留按钮禁用与等待图标，只在播放器拒绝操作或回复超时时显示错误。

- 修正原版设置成组选项被桌面玻璃样式覆盖选中状态的问题；启用／关闭、质量和背景类型等按钮补齐真实选中标记，采用更明确的主题填充、描边和文字，悬浮时保持选中效果，不添加勾选图标。
- 选中标记同时方便键盘和辅助工具识别；原参数、操作、禁用条件、导入导出及原版渲染器保持原有行为，高对比模式使用系统颜色与双线选中边框。

## 已保留的 0.4.1 修复（用户已确认解决）

- 继续播放、上下首使用重新解析的当前会话；明确更换播放器、实际断开或歧义会话仍拦截旧命令。
- 扫描进度先切回 UI 线程，再读取任何 WebView2 属性。取消扫描不覆盖原目录和索引；文件对话框与窗口移动循环在 WebView 回调退出后执行。
- 用自绘透明标题栏统一名称、图标、最小化、最大化和关闭按钮；边缘可调整大小，标题区域可拖动和双击最大化，退出全屏返回原窗口状态。
- 增加有大小上限的本地媒体诊断日志 `%LOCALAPPDATA%\FoliaLyrics\media.log`，记录来源、状态、控制能力和拒绝原因，不记录歌词或音频。

## 亚克力界面
- 整窗亚克力：透明 WebView 与 Windows DWM Desktop Acrylic 接合；原版动效通过公开的透明背景选项接入。
- 暖色浮动顶栏、胶囊底栏和磨砂设置面板。液态玻璃按钮带细边缘高光、跟随指针的反光与按压反馈，开关和输入框采用一致材质；底栏播放按钮为简洁白色图标。
- 原生亚克力需要 Windows 11 22H2（22621）或更新版本，并开启系统透明效果。不支持或关闭系统透明效果时使用内置磨砂背景；开启高对比度时使用可读性降级。主动选择透明歌词背景后显示后方窗口；鼠标穿透不再强制使用不透明背景。
- 名称图标与窗口按钮进入透明客户区，整窗使用同一原生亚克力背景。全屏切换、鼠标穿透恢复和系统主题变更时重新应用背景。
- 小窗口中设置面板独立滚动，底部播放控制保持可见；尊重系统减少动态效果设置。指针反光只在移动时更新，不驱动歌词组件逐帧重渲染。
- 修正暂停时切换部分动效可能空白的问题：桌面时钟将真实时间戳提供给新订阅的动效，不推进暂停中的播放进度，不修改原版渲染器。
- 保留 13 种原版动效、四源在线歌词以及外部播放器控制。

## 使用
1. 在常用播放器中播放音乐，再打开 FoliaLyrics.exe。
2. 识别到歌名、歌手和进度后，自动从启用的在线歌词源匹配；已有本地歌词或缓存时优先使用。
3. 不准确时，进入设置的“在线歌词”，修改歌名/歌手搜索并点击合适版本，选择会自动记住。也可添加音乐目录，或导入带内嵌歌词的音乐文件及 LRC / TTML / YRC / QRC / FIA。
4. 底部三个按钮控制外部播放器的上一首、暂停/继续、下一首；切歌后自动匹配新歌词。
5. 顶栏直接选择 13 种动效、显示译文和窗口置顶；右侧设置仍可调整歌词匹配、时间微调和声音响应。
6. 顶栏按钮进入/退出全屏；Esc 退出全屏、关闭设置或恢复控制栏。窗口沉浸时移到顶部呼出顶栏、底部呼出播放控件；开启鼠标穿透后，Ctrl+Alt+L 或双击托盘图标恢复。

## 兼容性与边界
- 目标系统为 Windows 11 x64。内置 .NET，无需用户另装 .NET；界面需要系统安装 Microsoft Edge WebView2 Runtime。
- 自动同步依赖播放器支持 Windows 系统媒体接口。不是听歌识曲或语音转歌词，也不读取播放器进程内存。
- 系统媒体接口通常不提供歌词。本版从 QQ 音乐、网易云音乐、酷狗音乐、LRCLIB 搜索歌词，并保留本地导入。在线请求仅传歌名、歌手、专辑、时长和已选歌曲标识；不上传音频、不修改原音乐。
- 播放器未提供进度时，可以在设置中开启手动歌词时钟，只推进歌词。
- 逐行 LRC 不能自动变成精准逐字歌词；逐字动效准确度依赖文件原有时间轴。本地加密歌词容器需先转换；在线 QQ QRC / 酷狗 KRC 由适配层解码。
- 声音响应读取默认音频输出设备的混合声音，仅在内存计算，不读取麦克风、不保存录音。ASIO、独占输出或其他设备可能没有声音响应；它不影响独立的时间同步功能。
- 配置、索引和缓存位于 %LOCALAPPDATA%\FoliaLyrics。
- 已在本地 Windows 11 上编译并启动 EXE，使用椒盐音乐验证播放进度、暂停继续、上下首、绘光切换、最大化还原及亚克力外观。长时间稳定性、多屏/DPI 与声音响应强度仍需进一步确认；完整范围见 VALIDATION.md。
- 程序未做商业代码签名，首次运行可能显示来源未知提示；不要关闭系统防护。需要核对文件时可查看交付的 SHA-256。

## 外部播放器控制
- 使用 Windows GSMTC 的 Play / Pause / SkipPrevious / SkipNext 请求；音乐仍由原播放器解码和输出。本软件不会启动音频播放、抢占音频设备或注册自己的播放会话。
- 先在音乐软件中播放一首歌。底部按钮跟随当前连接的播放器；设置中的“选择播放器”可固定应用，默认自动选择后持续绑定，暂停时也保留；要转到另一播放器可在设置中选择该应用。多个播放器同时运行时，建议明确选择要控制的应用。
- 按钮是否可用取决于播放器报告的能力。没有会话、已断开或未开放操作时禁用对应按钮。只支持切换播放状态的播放器使用系统提供的 Toggle 请求。
- 操作前校验会话标识、歌名/歌手/专辑；异步读取期间换歌或换来源会取消旧操作。连续点击不会排队执行；超过等待期限会显示错误，不自动重发。
- 收到成功回复只表示播放器接受请求；播放图标和歌词进度仍由实际会话数据更新。操作失败不会假装已暂停或切歌。
- 正常和等待中的控制只显示图标，成功回复不显示文字。仅操作失败或回复超时时出现错误；未连接或未开放操作时，相应按钮禁用并通过悬浮提示说明。
- 沉浸模式隐藏按钮，按 Esc 恢复。鼠标穿透时用 Ctrl+Alt+L 恢复操作。
- 手动歌词时钟仍是独立计时工具；它的“开始/暂停计时”仅控制歌词。手动模式下需要自行对齐时间，底部按钮仍只控制外部播放器。

## 在线匹配规则
- 默认启用四个歌词源，各源可独立关闭；总开关关闭联网后仍可读取已缓存的歌词。
- 手动选择的在线版本优先；否则先找本地歌词，再用在线缓存，最后联网。导入本地歌词会清除当前歌曲的在线手动绑定。
- 自动选择要求标准化后的歌名、歌手一致，并且时长相差不超过 2 秒；没有时长时需要专辑一致。其余结果只供手动选择，不会静默替换。
- 达到自动匹配条件时优先检查酷狗、QQ、网易云、LRCLIB，争取使用逐字版本；QQ 同时获取逐行回退。
- 缓存按歌名、歌手、专辑和时长隔离，最多保留 500 条；“重新自动匹配”会清除当前绑定和缓存后再按本地优先顺序查找。
- 缓存位于 %LOCALAPPDATA%\FoliaLyrics\online-lyrics，与原音乐文件分开。快速切歌会取消旧请求，旧结果不会覆盖新歌曲；网络请求不会阻塞播放进度轮询。
- 遇到限流遵守 Retry-After。同一服务的请求保持串行并至少间隔 300 ms，设置请求超时和响应体积上限。
- 接口可用性和歌词覆盖取决于第三方。本版不要求输入账号；截图中的汽水、Apple Music、Spotify 歌词源未接入。

## 工程边界
此衍生工程使用独立的 .NET 桌面宿主。`MediaMonitor` 负责读取与绑定会话，`MediaTransport` 负责能力校验与请求串行化，`WindowsMediaControlTarget` 是 Windows API 适配器；`PlaybackControls.tsx` 仅发送控制请求并显示系统返回状态。`native/Online/OnlineLyrics.cs` 是多源门面，各 provider 负责网络与数据标准化；WebView 界面仅使用统一消息协议，原 Folia 的 Web/Electron Omni 模块保持原状。原版 QRC 解码器及歌词解析器复用在 `parseDesktopLyrics.ts`，渲染器只接收标准歌词数据。

## 重新编译
安装 Node.js 24+ 与 .NET SDK 10，运行 build-windows.cmd。或执行：
```
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck:desktop
npm run build:desktop
npm run test:desktop
node tools/package-web.mjs
dotnet publish native/FoliaLyrics.csproj -c Release -r win-x64 --self-contained true -o release/win-x64
```

本机已将 Node.js 24 与 .NET SDK 10 单独准备在 `%LOCALAPPDATA%\FoliaLyricsBuild`；构建脚本会优先使用该目录中的工具，并检查所需版本，不修改系统 PATH。其他电脑仍需准备构建环境。
