# 桌面版上游同步

## 2026-11-17：v0.7.29 后的主线

本轮从 `a755f88a3592e9d5944e1a560b4bb87333aba000` 审查至 `cdb08291ddb7c91463ea626b58f1f55ec3d986c8`，共 42 项提交（含合并提交）。本轮同步纳入桌面正式版本 0.5.7，发布标签为 `desktop-v0.5.7`，本地发布目录为 `release/0.5.7/`。此前 0.5.6 本地测试包继续保留。

| 范围 | 桌面版处理 |
| --- | --- |
| 隐喻 Metaphor | 新增墨色融球、半调网点、物理线稿、硬切镜头、纯音乐分段画面、画面反相及可选关键字着色；接入本地智能动感「湮灭对撞」 |
| 桌面设置 | 新样式加入搜索、随机候选、静态预览图、JSON 与短码；设置编辑字段改由既有 tuning 注册表提供，避免新样式被固定白名单忽略 |
| 配置链接兼容 | 粘贴导入同时读取新链接的 `#cfg` 与旧链接的查询参数，片段优先；只解析文本，不访问该地址 |
| 字体 | 隐喻默认字重仍为 300；显式设置 CJK 字重时，测量和字形绘制使用同一个值 |
| 封面主题 | 主题按面积和感知色差聚类取色，强调色使用 OKLCH 亮度与色度；保留桌面主色不漂移、对比度、刷新可见变化和取消旧读取的约定，背景继续使用代表色入口 |
| TTML | 行级时间轴按词估算，长行折成多行后依次扫字；保留 ruby、鼓点及敏感词元数据 |
| 空闲调度 | 复用上游 `whenIdle`，为字形预建及既有预览提供可取消的空闲任务 |

不移植本轮电台墙、命令面板、远控四行歌词、OBS 页面及链接生成器、Electron 点击穿透置顶按钮及其存储键；只保留已有配置粘贴入口所需的链接格式兼容。桌面仍使用原生窗口、托盘和现有桥接，联网边界保持仅歌词搜索、下载和匹配；未增加平台请求、账户、播放、扩展或部署能力。上游发布版本号与发布新闻不进入桌面版本。

桌面集成回归另修复图片等 Portal 子窗口按 Escape 时被父 Studio 提前关闭的问题，子窗口自行处理按键，父窗口中的 Escape 仍正常关闭并提交。

验证结果见根目录 `VALIDATION.md`。

桌面仍只通过 `native/Online/OnlineLyrics.cs` 搜索、下载和匹配歌词。上游 provider 请求实现没有需要移植的变化；新增原名/别名匹配依赖其音乐库提供的额外元数据，当前 GSMTC 不提供这些字段。未恢复自动 AI 联网分词、账户、在线播放、电台、云同步、更新、远控、模组、网页部署、Electron 或 Stage HTTP 服务。

影厅不处理音乐音频，也不提供声线追踪：音乐继续由外部播放器播放。场景注册表只接受随安装包提供的内置实现，不接受运行时扩展或远程资源。现有本地视频、字体、素材、模型桥接和窗口权限限制继续适用。
